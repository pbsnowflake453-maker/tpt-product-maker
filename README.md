# TpT Product Maker — My Side of the Classroom

A static, browser-only website that generates printable Teachers Pay Teachers products for Samantha Wallace's store **My Side of the Classroom**. Pick a product type and a skill, preview the pages, and download an editable **PowerPoint** (main format, opens in Google Slides with no sign-in) or a **PDF**.

Products: **Roll and Read**, **Roll and Solve**, **Task Cards**, **Bingo**, **Mystery Picture** (color by skill / color by code), **Word Sort**, **Word Maze**, **Cold Read**, **Picture Write**, **Read and Draw** (decodable sentences + a drawing box), and six word-work page types: **Read and Draw: Words**, **Count the Sounds**, **Read, Draw and Count** (both on one page), **Letter Shapes**, **Missing Letters** (click letters to choose which ones are hidden), and **Letter Shapes + Missing Letters** (both on one page); the word list is any words she picks or types, and the page title can be edited. Any products can be **bundled** (landscape and portrait mixed) as a ZIP of separate numbered files: a Cover and Contents file plus one file per set, each as PowerPoint and PDF. Each product or bundle can also produce **TpT listing images** (colorful covers and previews with a page picker).

- Live (Netlify Drop): https://whimsical-paprenjak-e6c0cd.netlify.app/ — **publish directory: `site/`**
- No server, no build step, no sign-in. Libraries are vendored (jsPDF, PptxGenJS).

The older `spec/build_sample*.py` scripts have absolute paths from the original build box (`/workspace/...`); adjust before running.

## Build / test
- Regenerate data after editing word lists or pixel art (run from repo root):
  `python3 spec/build_from_megabank.py && python3 spec/build_sentences.py && python3 spec/build_wordinfo.py && python3 spec/build_pixels.py`
- Serve locally: `cd site && python3 -m http.server 8812` then open http://127.0.0.1:8812/
- Headless tests: Playwright (`npm i playwright`; env `PW`, `CHROME`, `BASE`, `OUT` override defaults), `node tests/suite.js` — scripts expect the server at 127.0.0.1:8812 and expose `window.APP` test hooks (`APP.product(id,kind)`, `APP.select(name)`, `APP.addSet()`, `APP.paintAt()`, `APP.bgOff()`...). Render downloaded PDFs with `pdftoppm` and compare visually against the approved look.
- Deploy: zip the **contents** of `site/` and drop on Netlify. **Ask Samantha before publishing changes.**

See **AGENTS.md** for all approved style and product rules.

## UFLI and Text Checker (branch update, November 15, 2026)

- `data-src/phonics_words.csv` now includes Samantha's four UFLI columns. All 4,371 existing rows and their CKLA fields are preserved. Regenerate with the existing three bank/sentence/word-info commands.
- The reading picker has **UFLI Lessons** (words first decodable in that lesson) and **UFLI Cumulative** (words decodable through that lesson). Pools use UFLI tags independently of CKLA placement, include tagged word forms, omit names, and omit heart words until an explicit `ufli_decodable_lesson` is reached. There are no invented future-word challenge pools. Some UFLI lessons have no newly tagged words in this bank, so only their cumulative choice is available. Cumulative pools are populated by `js/wordbank.js` from `data/wordbank.js` at startup to avoid downloading the same rows hundreds of times.
- **Text Checker** (`site/checker.html`) accepts pasted text, TXT/MD/CSV, selectable-text PDFs, DOCX and PPTX. Scanned/image-only documents need pasted text. It checks exact CKLA unit/lesson or UFLI lesson, before or after instruction; before is the default. The optional Unit 1 review exception applies to non-tricky patterns only. CKLA tricky words are accepted after their introduction; UFLI has a separate option to accept introduced heart words. Accepted heart/tricky words are marked separately from phonically decodable words. Missing tags are reported, never inferred.
- The report separates later/unmapped words from unknown words, marks every occurrence, and has a deduplicated complete list sorted by all of each word's phonics tags. Copy and CSV export are provided.
- Unknown words can be added individually with phonics, form, syllable, CKLA and UFLI tags. Browser additions are saved under `tpt-wordbank-additions-v1` in local storage, apply on this origin/device, and survive reload. They join matching tagged skill/category pools, CKLA unit pools, UFLI pools, and their own **My Added Words** pools. Drawable/tricky metadata is loaded on Product Maker startup; sound-count eligibility is still generated by `spec/build_wordinfo.py` after a canonical CSV update. JSON export/import transfers additions to another device; complete-bank CSV export can replace the repository source and be regenerated later. **The static site does not write to GitHub or synchronize browser storage across devices.**
- **Bold Spotlight** is a listing style in Product Maker, bundles and Listing Image Maker. It uses black/white title bands, actual page previews in a fan, and accent callouts. Both listing styles support ten palettes: apple, sky, sunny, grape, mint, lime, teal, coral, rose and peach. Printed student products retain their existing monochrome styling.

### Validation

`node tests/bank.js` runs without dependencies and checks every bank row's CKLA boundary, UFLI pools/heart transitions, tokenization, unknown/unmapped distinctions, additions, CSV and backup import.

`node tests/features.js` uses the offline DOM/canvas harness in `tests/offline.js` (jsdom and @napi-rs/canvas, configured using the `JSDOM` and `CANVAS` module paths). It builds all offered reading skills across nine products, exports each product as PDF/PPTX/PNG, checks UFLI 56, mixed bundles, all palettes/styles, the checker/tagging UI and file extraction. This harness is functional coverage, not a replacement for browser layout testing. `node tests/pdf.js` additionally exercises the actual vendored PDF text extractor and worker cleanup. Existing Playwright suites remain the browser regression checks; use `PW` and `CHROME` as described in `tests/lib.js`.
