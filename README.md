# TpT Product Maker — My Side of the Classroom

A static, browser-only website that generates printable Teachers Pay Teachers products for Samantha Wallace's store **My Side of the Classroom**. Pick a product type and a skill, preview the pages, and download an editable **PowerPoint** (main format, opens in Google Slides with no sign-in) or a **PDF**.

Products: **Roll and Read**, **Roll and Solve**, **Task Cards**, **Bingo**, **Mystery Picture** (color by skill / color by code), **Word Sort**, **Word Maze**, **Cold Read**, **Picture Write**, **Read and Draw** (decodable sentences + a drawing box), and six word-work page types: **Read and Draw: Words**, **Count the Sounds**, **Read, Draw and Count** (both on one page), **Tricky Words: Letter Shapes**, **Tricky Words: Missing Letters**, and **Tricky Words: Shapes + Missing Letters** (both on one page). Any products can be **bundled** (landscape and portrait mixed) as a ZIP of separate numbered files: a Cover and Contents file plus one file per set, each as PowerPoint and PDF. Each product or bundle can also produce **TpT listing images** (colorful covers and previews with a page picker).

- Live (Netlify Drop): https://whimsical-paprenjak-e6c0cd.netlify.app/ — **publish directory: `site/`**
- No server, no build step, no sign-in. Libraries are vendored (jsPDF, PptxGenJS).

## Layout
```
site/                     <- publish this folder as-is
  index.html, style.css
  js/core.js              page model (inches), fonts, logo, text wrap, canvas/PDF/PPTX renderers, assemble() for bundles
  js/math.js              math skill menu + problem banks
  js/picker.js            searchable grouped skill combobox
  js/app.js               UI (product/kind, picker, options, mystery editor, bundles)
  js/bundle.js            bundles: zip of separate files (01 Cover and Contents + one numbered file per set, PPTX + PDF)
  js/listing.js           TpT listing images (zip of PNGs + listing.txt) with the page picker
  js/products/*.js        rollread, rollsolve, taskcards, bingo, mystery, wordsort, wordmaze, coldread, picturewrite, readdraw, wordwork (one module each; wordwork.js holds the six word-work products)
  data/skills.js          reading skills + categories + Unit / Through Unit options (GENERATED by spec/build_from_megabank.py)
  data/sentences.js       decodable sentences for Read and Draw (GENERATED by spec/build_sentences.py)
  data/wordinfo.js        drawable words, 2-5 sound words, tricky-word picker list, irregular letters (GENERATED by spec/build_wordinfo.py)
  data/pixels.js          pixel-art library (GENERATED by spec/build_pixels.py)
  fonts/                  Pacifico, Andika (Regular/Bold), Fredoka-Bold (static instance of Google Fredoka)
  assets/logo.png         store logo
  vendor/                 jspdf.umd.min.js, pptxgen.bundle.js
spec/                     Python reference/spec scripts (python-pptx samples Samantha approved) + data tools
  build_sample.py, build_math_sample.py, build_taskcards_sample.py
  build_from_megabank.py  Mega Word Bank CSV -> site/data/skills.js (skills, categories, Unit / Through Unit, display names) + data-src/bank_index.json
  build_sentences.py      data-src/sentences/u1..u7.txt -> site/data/sentences.js; fails if any word is outside the bank/unit/names list
  build_wordinfo.py       data-src/phonics_words.csv + data-src/tricky_irregular.json -> site/data/wordinfo.js (word-work pages)
  bank_vocab.py           prints each unit's new words by part of speech (for writing sentences)
  build_pixels.py         data-src/pixel-library.json -> site/data/pixels.js
data-src/phonics_words.csv   Samantha's Mega Word Bank (the only source of reading words)
data-src/sentences/       decodable sentences by CKLA unit (u1..u7.txt)
data-src/pixel-library.json  pixel-art library (source of truth for Mystery Picture images)
tests/                    Playwright tests: suite.js (assertions), wordwork.js (the six word-work products), all.js (render every product), lib.js (setup); legacy/ = old ad hoc scripts
```
The older `spec/build_sample*.py` scripts have absolute paths from the original build box (`/workspace/...`); adjust before running.

## Build / test
- Regenerate data after editing word lists or pixel art (run from repo root):
  `python3 spec/build_from_megabank.py && python3 spec/build_sentences.py && python3 spec/build_wordinfo.py && python3 spec/build_pixels.py`
- Serve locally: `cd site && python3 -m http.server 8812` then open http://127.0.0.1:8812/
- Headless tests: Playwright (`npm i playwright`; env `PW`, `CHROME`, `BASE`, `OUT` override defaults), `node tests/suite.js` — scripts expect the server at 127.0.0.1:8812 and expose `window.APP` test hooks (`APP.product(id,kind)`, `APP.select(name)`, `APP.addSet()`, `APP.paintAt()`, `APP.bgOff()`...). Render downloaded PDFs with `pdftoppm` and compare visually against the approved look.
- Deploy: zip the **contents** of `site/` and drop on Netlify. **Ask Samantha before publishing changes.**

See **AGENTS.md** for all approved style and product rules.
