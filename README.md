# TpT Product Maker — My Side of the Classroom

A static, browser-only website that generates printable Teachers Pay Teachers products for Samantha Wallace's store **My Side of the Classroom**. Pick a product type and a skill, preview the pages, and download an editable **PowerPoint** (main format, opens in Google Slides with no sign-in) or a **PDF**.

Products: **Roll and Read**, **Roll and Solve**, **Task Cards**, **Bingo**, **Mystery Picture** (color by skill / color by code). Any products can be **bundled together** (any mix of product types and skills). A bundle downloads as a zip: a cover/contents file plus one separate file per set.

- Live (Netlify Drop): https://whimsical-paprenjak-e6c0cd.netlify.app/ — **publish directory: `site/`**
- No server, no build step, no sign-in. Libraries are vendored (jsPDF, PptxGenJS).

## Layout
```
site/                     <- publish this folder as-is
  index.html, style.css
  js/core.js              page model (inches), fonts, logo, text wrap, canvas/PDF/PPTX renderers, assemble() for bundles
  js/math.js              math skill menu + problem banks
  js/picker.js            searchable grouped skill combobox
  js/app.js               UI (product/kind, picker, options, mystery editor, bundles)
  js/bundle.js            bundle cover + contents file, per-set file names, zip of PPTX/PDF files
  js/listing.js           TpT listing packs (single product and bundle, with picked thumbnail pages)
  js/products/*.js        rollread, rollsolve, taskcards, bingo, mystery (one module each)
  data/skills.js          reading skills + categories + CKLA units (GENERATED by spec/make_categories.py)
  data/pixels.js          pixel-art library (GENERATED by spec/build_pixels.py)
  fonts/                  Pacifico, Andika (Regular/Bold), Fredoka-Bold (static instance of Google Fredoka)
  assets/logo.png         store logo
  vendor/                 jspdf.umd.min.js, pptxgen.bundle.js
spec/                     Python reference/spec scripts (python-pptx samples Samantha approved) + data tools
  build_sample.py, build_math_sample.py, build_taskcards_sample.py, build_bingo.py, build_mystery.py
  make_categories.py      builds categories, CKLA unit options, display names -> spec/wordlists_audited.json + site/data/skills.js
  build_pixels.py         data-src/pixel-library.json -> site/data/pixels.js
  wordlists_audited.json  CKLA-audited word lists (source of truth for reading words)
data-src/pixel-library.json  pixel-art library (source of truth for Mystery Picture images)
tests/                    Playwright scripts used for headless testing
```
The `spec/build_*.py` scripts have absolute paths from the original build box (`/workspace/...`); adjust before running.

## Build / test
- Regenerate data after editing word lists or pixel art (run from repo root):
  `python3 spec/make_categories.py && python3 spec/build_pixels.py`
- Serve locally: `cd site && python3 -m http.server 8812` then open http://127.0.0.1:8812/
- Headless tests: Playwright (`npm i playwright`), e.g. `node tests/t.js` — scripts expect the server at 127.0.0.1:8812 and expose `window.APP` test hooks (`APP.product(id,kind)`, `APP.select(name)`, `APP.addSet()`, `APP.paintAt()`, `APP.bgOff()`...). Render downloaded PDFs with `pdftoppm` and compare visually against the approved look.
- Deploy: zip the **contents** of `site/` and drop on Netlify. **Ask Samantha before publishing changes.**

See **AGENTS.md** for all approved style and product rules.
